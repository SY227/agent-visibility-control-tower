# Pitch deck source

This folder contains the editable source used to generate the PowerPoint deck.

## Files

- `generate_deck.py` — generates the `.pptx`
- `deck_content.md` — slide-by-slide content outline
- `screenshots_to_capture.txt` — manual screenshot list for final insertion

## Output

Running the script writes:

- `../agent_visibility_control_tower_pitch_deck.pptx`

## Notes

- The deck is designed to mirror the app's calm green visual system.
- Screenshot areas are intentionally placeholders for manual replacement.
- PowerPoint remains the primary editable format after generation.
